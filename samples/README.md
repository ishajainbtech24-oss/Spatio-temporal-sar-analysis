# Samples

| Folder | What it is | Use |
|---|---|---|
| `synthetic/` | Synthetic chips in Sen1Floods11 `S1Hand` / `LabelHand` format, generated by `scripts/make_demo_samples.py`. **Not real Sentinel-1 data.** | Demonstrates the dashboard and CLI end to end without downloading the dataset. |
| `legacy/` | The three images that were in `app/uploads/` of the original dashboard. Their origin and processing are unknown (8-bit, no georeferencing, no calibration). | Kept for continuity; only the legacy classifier and a relative Otsu split can run on them. |

To try real data, copy any `*_S1Hand.tif` (and optionally its `*_LabelHand.tif`) from Sen1Floods11 into a new folder here, e.g. `samples/sen1floods11/`. The dashboard lists every subfolder.
